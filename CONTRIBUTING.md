# Contributing

Thank you for improving this beginner-focused DevOps coach.

## Good contributions

- Correct an inaccurate concept or obsolete official link.
- Add a deterministic, low-cost lab with teardown instructions.
- Improve a Chinese explanation or its natural English counterpart.
- Add tests for scheduling, prerequisites, adaptation, privacy, or schemas.
- Improve accessibility without weakening an evidence gate.

## Workflow

1. Create an `agent/<short-description>` branch.
2. Keep personal learner data out of the change.
3. Install development dependencies with `python -m pip install -e ".[dev]"`.
4. Run all verification commands listed in `AGENTS.md`.
5. Open a draft pull request explaining the change, learner impact, and checks.

Do not add paid-only resources as the sole path through a required module. Do not replace hands-on evidence with certificate preparation.
